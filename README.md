# Discord All-in-One Bot

Bot Discord all-in-one tanpa AI dengan Node.js 18+, discord.js v14, SQLite via better-sqlite3.

## Modul
1. Moderasi (auto-mod, warn/mute/kick/ban/timeout/purge, points/cases, log, anti-nuke, backup)
2. Leveling & Ekonomi (XP, leaderboard, daily/weekly/work, mini games, kartu rank)
3. Musik (play/pause/skip/stop/queue/volume/loop/filters)
4. Utilitas (reminder, timer, poll, giveaway, ticket, translation, server/user info)
5. Kustomisasi (welcome/goodbye, reaction roles, custom cmd, auto-responder, autorole, sticky)
6. Fitur Pembeda (anti-nuke + rollback, server backup, analytics, system plugin)
7. Dashboard Web (OAuth2, config per server, log & analytics, responsive)

## Setup
1. `npm install`
2. Isi `.env` (salin dari `.env.example`)
3. `npm run deploy`
4. `npm start`
5. `node src/dashboard.js` (dashboard)
